# Neovim Configuration

## Prompt
**Objective**
Please create the most optimal, performant, documented, modularized neovim configuration possible.

**Audience**
This configuration is intended for a senior full stack engineer that works across multiple repositories and projects. This includes code contribtions as well as PR reviews and code/debugging investigations and archtiecture design.

**Requirements**
You most include a package manager and use the most optimal, performant, popular and rated plugins as needed.

The most common and sensible default settings should be applied in a modular fashing that documents what it does and how to use it.

The configuration most be fully IDE-like, similar to VS-code supporting:
1. LSP support - e.g. go to definition, find references, look up arguments, etc.
    Languages to support:
    1. Typescript
    2. Python
    3. Rust
    4. html
    5. css/scss
    6. markdown
    7. bash
    8. angular
    9. react/tsx
2. autocomplete
3. autoimport
4. syntax highlighting
5. Formatting and linting
    1. prettier
    2. eslint
    3. oxlint
    4. oxfmt
6. File explorer
7. Fuzzy finder
8. git support
9. CoPilot integration
10. Terminal integration

and any other common plugins for the most efficient and optimal developer experience.
